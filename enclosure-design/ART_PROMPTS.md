# One-ink crest prompt record

Generated with the built-in image tool. Three separate assets, each referenced to existing local game images. The originals are in assets/*-crest-reference.png. The finished native SVG path versions remove all shading and retain one solid ink with transparent negative space.

## Shared prompt

Create a clean production-oriented single-color fantasy emblem, solid BLACK ink shapes only on a genuinely transparent background. No colored pixels, gray shading, gradients, shadows, mockup surfaces or text. Broad confident silhouette and negative-space cuts, minimal details, clean edges, generous open spaces. This is for vinyl or engraving at 55–70mm wide, so avoid hairlines and micro ornaments. Centered square composition with margin. Use the existing game references for character identity and world motifs, not a generic unrelated fantasy character. One unified crest, not multiple options.

## Explorer

References: images/explorer.png and images/title-screen.png.

EXPLORER CREST: the reference game's young short adventurer, recognizable rounded fur-trimmed cap, large eyes, tunic, backpack and little lantern. A waist-up three-quarter portrait looking to the right, lantern extended, with a bold broken-arch crest and a simple reveal-eye or sunburst motif. Simplify the cap fur into 3 large shapes, face into only a few negative-space marks. No wizard, no beard. Match the style of a companion emblem for the bearded Architect.

## Architect

## Main

MAIN PORTAL CREST: use the reference title artwork's ruined stone portal, central diamond rune and maze/bridge symbols. A strong stylized circular-to-arched portal with a large diamond rune in its center, two paths converging at its base, and only a few broad rune-circuit branches that suggest coordination of two players. No people, no radio antenna, no wireless icon, no lettering. A compact flat emblem that matches the companion Explorer and Architect character crests.

## Production conversion

The native SVG conversion treats dark opaque pixels as ink and light/transparent pixels as negative space. It uses a single black path fill, with a white-path companion for dark surfaces. Small raster specks are removed during tracing. Original references remain unchanged. Technical layout artwork is authored directly as SVG so component openings and artwork stay separate. Check the final physical-size print or engraving sample before vinyl weeding or applying the smaller top-panel crest.
