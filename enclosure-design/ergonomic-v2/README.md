# Dual-Reality Maze — ergonomic design review 2

Open `index.html` in a browser. Each role offers Exterior, Exploded CAD and Internal plan views.

- `DESIGN_REVIEW.md`: shapes, grip reasoning, dimensions, internal placement, master power architecture, screwless approach, UIC requirements, code status and unresolved fit work.
- `COMPONENT_REFERENCE.csv`: published dimensions, source links and explicit planning allowances.
- `cad/ergonomic_enclosures.scad`: editable OpenSCAD source. Set role to explorer/architect/main and part to assembly/exploded/base/lid/guard/crystal. Units are mm.
- `cad/geometry-validation.json` and `VALIDATION.json`: mesh and layout checks. These do not qualify physical fit or electronics.
- `assets/*-decal.svg`: one-color vector artwork, 56 mm controller or 42 mm Main artboards. Original 70 mm crests remain alongside them.
- `previews/` and `layouts/`: actual CAD renders, internal layouts and family overview.

This is a design study. Final component holders, lid locking keys, power-button travel/retention, horn keeper, cable fit and ergonomic testing are not complete. No manufacturing STL release or fabrication submission is implied. No game firmware was added or uploaded in this enclosure revision. Older enclosure ZIPs and presentation packages retain their earlier design revision.
